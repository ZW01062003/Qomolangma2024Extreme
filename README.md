# Qomolangma2024Extreme
This code repository provides Python scripts for generating charts used to study the extreme precipitation event that occurred on the northern slope of Mount Everest on 27–28 September 2024. We have integrated data from high-altitude observation stations, GPM IMERG, ERA5-Land, ERA5 atmospheric fields and nested WRF numerical simulation results to examine the typical relationship between precipitation and altitude from June to September, how this relationship manifested during the extreme precipitation event of 2024, and the associated circulation and local water vapour processes.

Code and data availability

The plotting scripts are available in this repository under its `LICENSE`. **The repository does not provide the station observations.** Those observations are subject to their own data-use arrangements; availability should be described in the manuscript's Data Availability statement.
